# DarkVerse Lab — Safe Simulator

Versi web aman dari konsep DarkVerse. Ini adalah training lab/simulator lokal.

## Fitur
- Dashboard telemetry
- Traffic/rate-limit simulation tanpa network request
- OTP stress-test simulator tanpa SMS/provider
- Mock web scanner dengan fixture lokal
- Bug report lab
- Activity logs lokal

## Menjalankan
Bisa langsung buka `index.html` di browser. Untuk hosting statis, upload folder ini ke Vercel/Netlify/GitHub Pages.

## Batas keamanan
Tidak ada fungsi untuk mengirim spam/OTP, DDoS, eksploitasi, atau scanning target nyata.
